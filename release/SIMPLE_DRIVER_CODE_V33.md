# V33 · asignación simple del código del domiciliario

La llave 🔑 queda como una acción administrativa directa:

1. Abrir la llave del domiciliario.
2. Escribir un código de 4 números.
3. Guardar.
4. Entregar ese código al colaborador.

No se solicita ni se valida el código anterior.

Al guardar:
- el PIN real de acceso se cambia al valor escrito;
- la copia administrativa se actualiza con el mismo valor;
- el nuevo código es el que se usa para próximos inicios de sesión;
- el administrador puede volver a entrar a la llave y cambiarlo cuando lo necesite.

No modifica pedidos, tarifas, documentos, QR, chat ni notificaciones.
