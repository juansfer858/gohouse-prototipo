# V30 · consulta administrativa del código del domiciliario

- Botón 🔑 **Ver código** junto a cada domiciliario.
- Domiciliarios nuevos: el código queda disponible para consulta desde el momento de creación.
- Domiciliarios existentes: si todavía no hay copia administrativa, el panel permite registrar su código actual; el servidor lo valida con el acceso real y no lo modifica.
- Solo usuarios con rol **administrador** pueden consultar o registrar códigos.
- El código de acceso sigue siendo permanente e inmutable mientras el domiciliario exista.
- Al eliminar al domiciliario se elimina también la copia administrativa.
- No modifica pedidos, tarifas, documentos, QR, chat ni el flujo del domiciliario.
