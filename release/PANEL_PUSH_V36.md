# V36 · notificaciones push en el panel

Se añade un control permanente en el panel administrativo.

Estados:
- 🔔 Activar notificaciones
- 🔔 Notificaciones activas
- 🔕 Notificaciones bloqueadas

Al activar:
- el navegador solicita permiso;
- el panel se suscribe al VPS;
- se muestra una notificación local de confirmación;
- el panel queda listo para recibir nuevos pedidos, mensajes de clientes y comprobantes.

Si el navegador bloqueó el permiso, el botón explica que debe habilitarse desde el candado de la barra de direcciones.

No modifica pedidos, tarifas, correo, códigos, documentos, QR ni chat.
